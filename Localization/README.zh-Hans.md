DiCivil Manage 包含 5 款专注于数据管理工作流程的 Autodesk Civil 3D 工具。
本指南通过分步说明和动画 GIF 介绍每款工具的工作方式。

### DiCivil Manage 包含
- Style Helper
- Template Inspector
- Drawing Layers
- Transfer Object Layers
- Transfer Survey Standards

### 支持的 Civil 3D 版本
2022、2023、2024、2025、2026 和 2027。
