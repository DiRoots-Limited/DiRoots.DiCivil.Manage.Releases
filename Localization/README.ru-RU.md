Упростите управление данными Civil 3D с помощью инструментов для редактирования стилей в таблицах, проверки объектов, управления слоями и состояниями, а также переноса стандартов съемки и слоев объектов.

DiCivil Manage включает 5 инструментов Autodesk Civil 3D для оптимизации процессов управления данными.
В руководстве работа каждого инструмента объясняется пошагово с помощью анимированных GIF.

### В состав DiCivil Manage входят
- Style Helper
- Template Inspector
- Drawing Layers
- Transfer Object Layer
- Transfer Survey Standards

### Поддерживаемые версии Civil 3D
2022, 2023, 2024, 2025, 2026 и 2027.
